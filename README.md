# ⚡ ECHO-PARADOX 3D — Duel Temporel Holographique

Jeu multijoueur 3D en temps réel (Solo vs Bot IA, 2 Joueurs Local, et Multijoueur Mondial P2P via WebRTC).

## 🚀 Déployer sur Vercel depuis GitHub

1. Crée un nouveau dépôt (repository) sur [GitHub](https://github.com/new) nommé `echo-paradox-3d`.
2. Envoie les fichiers de ce dossier (`index.html`, `vercel.json`, `package.json`, `README.md`) sur ton dépôt GitHub :
   ```bash
   git init
   git add .
   git commit -m "Initial commit: ECHO-PARADOX 3D"
   git branch -M main
   git remote add origin https://github.com/TON-PSEUDO/echo-paradox-3d.git
   git push -u origin main
   ```
3. Va sur [vercel.com/new](https://vercel.com/new), clique sur **Import** à côté de ton dépôt `echo-paradox-3d`, puis clique sur **Deploy**.
