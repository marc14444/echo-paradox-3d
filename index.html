▲ Déployer ECHO-PARADOX 3D sur Vercel

Ce jeu est conçu avec une architecture 100 % statique (Three.js + WebRTC PeerJS). Tu n'as besoin d'aucun serveur backend payant pour que des joueurs du monde entier s'affrontent !

🚀 Étape 1 : Préparer le dossier

Télécharge ce fichier HTML et renomme-le index.html dans un dossier echo-paradox.

🌐 Étape 2 : Mettre en ligne sur Vercel (30 sec)
  • Connecte ton compte sur vercel.com (gratuit).
  • Importe ton dépôt GitHub ou utilise la commande npx vercel dans ton dossier.
  • Vercel te donne immédiatement une URL mondiale en HTTPS (ex: echo-paradox.vercel.app).
🔥 Étape 3 : Pourquoi le multijoueur marche déjà ?

Le mode En Ligne Mondial utilise PeerJS (WebRTC) : dès que deux joueurs entrent le même code à 4 chiffres sur ton lien Vercel, leurs navigateurs se connectent directement en pair-à-pair à 60 FPS !
